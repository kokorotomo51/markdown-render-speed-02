A dependency-free, from-scratch Markdown renderer that returns byte-for-byte the HTML marked 18.1.3 renders with its default options (GFM on, breaks off) — but faster. The parser is a default-specialized implementation of marked's block/inline lexing algorithm: no option merging, no extensions, no hooks, no async paths, with module-level precompiled regexes and direct HTML rendering from the token stream.

## Run it

```sh
node main.ts
```
